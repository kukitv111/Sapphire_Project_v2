Sapphire — современная платформа управления компьютерными клубами

Sapphire — это программная платформа нового поколения для автоматизации работы компьютерных клубов, киберспортивных арен и игровых пространств. Проект создается как современная альтернатива существующим решениям, таким как Gizmo, SmartShell и SENET, с упором на высокую производительность, удобство использования и гибкость настройки.

На первом этапе Sapphire будет работать без поддержки Diskless-систем, сосредоточившись на максимально стабильной и функциональной клиент-серверной архитектуре. В дальнейшем архитектура проекта позволит добавить поддержку бездисковой загрузки как отдельного модуля.

Основные возможности
Управление игровыми компьютерами и игровыми зонами.
Авторизация клиентов по аккаунту, номеру телефона, QR-коду или карте клуба.
Управление тарифами, пакетами времени и бонусными программами.
Онлайн-бронирование компьютеров и VIP-комнат.
Контроль состояния каждого ПК (онлайн, офлайн, занят, свободен, обслуживание).
Запуск, завершение и автоматический контроль игровых сессий.
Автоматическая блокировка рабочего стола до авторизации пользователя.
Управление установленными играми и приложениями.
Централизованное обновление клиента.
Встроенная система уведомлений и сообщений.
Подробная статистика по посещаемости, доходам и загрузке клуба.
Система ролей для администраторов, кассиров и владельцев.
Поддержка нескольких филиалов с единым центром управления.
REST API для интеграции с внешними сервисами и мобильными приложениями.
Преимущества Sapphire
Современный минималистичный интерфейс.
Высокая скорость работы даже при сотнях подключенных компьютеров.
Модульная архитектура, позволяющая легко расширять функциональность.
Повышенная безопасность соединения между сервером и клиентами.
Простая установка и обновление.
Гибкая система лицензирования.
Возможность локальной работы без постоянного подключения к интернету.
Поддержка Windows 10 и Windows 11.
Будущее развитие

После выпуска стабильной версии планируется постепенное расширение возможностей платформы:

поддержка Diskless-инфраструктуры;
мобильное приложение для владельцев клубов;
мобильное приложение для клиентов;
веб-панель управления;
облачная синхронизация нескольких филиалов;
интеграция с платежными системами;
аналитика с использованием искусственного интеллекта;
автоматическое управление обновлением игр через Steam, Epic Games, Riot Games и другие лаунчеры.
Миссия проекта

Sapphire создается как современное, быстрое и надежное решение для владельцев компьютерных клубов. Цель проекта — предоставить удобный инструмент, который автоматизирует повседневные процессы, уменьшит нагрузку на персонал и позволит владельцам сосредоточиться на развитии своего бизнеса, а не на технических сложностях.
